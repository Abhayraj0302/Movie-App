🎬 Excited to share my first Android project 
As someone who just started learning Android development, I challenged myself to build a fully functional movie discovery app from scratch using Jetpack Compose. No tutorials followed step by step — just learning by doing and figuring things out along the way.


What I built:
🏠 Home screen with trending, popular & top rated sections
🔍 Search screen with real-time filtering
❤️ Save your favourite movies
👤 Profile screen with editable name & email
⚙️ Settings with toggle switches


Tech I learned building this:
→ Jetpack Compose for modern declarative UI
→ Navigation Component for multi-screen flow
→ State hoisting & shared state across screens
→ Reusable composables
→ Sealed classes & Kotlin best practices
→ LazyColumn & LazyVerticalGrid for performance


This project taught me more than any tutorial ever could. I made mistakes, debugged crashes, read Logcat, and figured things out one error at a time. That process is what real learning feels like.
Currently working on integrating the TMDB API with Retrofit and adding MVVM architecture to make it production-ready.
If you're also a beginner — just start building. You'll learn more from one real project than ten courses.
Open to internship opportunities in Android development! 🚀
